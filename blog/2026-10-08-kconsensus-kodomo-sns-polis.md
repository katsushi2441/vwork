名古屋でAIシステム開発の会社をやっています。10月8日、Claude Code に「デジタル民主主義2030って、活発なプロジェクトと言えるの？」と聞いたところから始まって、夜には当社の合意点マップに「子どもとSNS」の論点を足して公開するところまで進みました。その経緯と結果を書きます。

- [Kurage 合意点マップ「子どもとSNS」](https://kurage.exbridge.jp/kconsensus.php/t/kodomo-sns/?ref=vibeblog_kconsensus-sns)（無料・登録不要で賛否を押せます）
- [Kurage 合意点マップ（Pol.is 互換）を自社に置く](https://kappstore.exbridge.jp/app.php?id=d88a943736386fb3&ref=vibeblog_kconsensus-sns)

## 1. デジタル民主主義2030は活発か

デジタル民主主義2030（DD2030）は、チームみらいの安野貴博党首が2025年に立ち上げたコミュニティです。広聴AI・いどばた・Polimoneyの3つのオープンソースを作っています。Slackの公開チャンネルと、GitHubの動きを数えました（10月8日時点）。

| 項目 | 数字 |
|---|---|
| Slackの公開チャンネル | 59 |
| 直近30日に書き込みがあったチャンネル | 約10（残り40以上は0件） |
| 1か月に書き込む人 | 16人（2026年9月。ピークの2025年5月は138人） |
| 広聴AIのコミット（直近30日） | 73件・7人。うち54件（74%）は西尾泰和さん1人 |
| 広聴AIのコミット（直近90日） | 81件（7月〜9月上旬の2か月は8件だけ） |
| いどばた・Polimoneyのコミット（直近30日） | 0件 |

1,600人が登録した場所で、数人の中心メンバーが広聴AIを作り続けている、というのが実態でした。活発なコミュニティとは言えません。

## 2. 新しいものを作ろうとしているか

広聴AIのREADMEには、「AI Objectives Institute が開発した Talk to the City を参考に開発し、ライセンスに基づいてソースコードを一部活用」と書かれています。ブロードリスニングの考え方も、Pol.isと、それを台湾の vTaiwan で使ったオードリー・タンさんの流れから来ています。

いま開発チャンネルで話されているのは、自治体のPCで動かす手順、モデル一覧の整理、依存ライブラリの修正といった整備です。アルゴリズム開発のチャンネルは8月21日から書き込みがありません。新しい方式を生み出そうとしている気配は、数字からも話題からも見えませんでした。

## 3. 「未来版Pol.is」は、もうある

チームみらいは10月6日、党の中に「広聴本部」を作ったと発表し、これから作るものとして「未来版Pol.is」を挙げました。意見に賛否を押してもらい、意見の分かれ方を地図にして、立場の違う人が乗れる案を探すものです。

これは、当社が**9月19日**に公開した [Kurage 合意点マップ](https://kurage.exbridge.jp/kconsensus.php/?ref=vibeblog_kconsensus-sns) とほぼ同じです。しかも合意点マップは、Pol.isの弱点を1つ先に越えています。

- **Pol.isの弱点**：意見を投稿する人が集まらないと、合意点が出ない
- **合意点マップのやり方**：意見を待たずに、国会の発言とニュースへの反応から論点を立てる。AIは実在の発言を「賛否を押せる1文」に言い換えるだけで、意見の中身は作らない。賛否の傾向で近い人どうしをグループに分け、どのグループからも賛成が多い点を出す

チームみらいの広聴本部が実演した「子どもとSNS」のAIインタビューは、約1か月で219人が答えました。党の告知を見て、10分のインタビューに答える人たちです。それより、ネットですでに出ている数千・数万の声から論点を立てたほうが、支持者でない人の論点も入ります（詳しくは[チームみらいの広聴本部に声は集まるか](https://exbridge.jp/vibeblog/2026-10-07-team-mirai-kouchou-honbu-koe.html?ref=vibeblog_kconsensus-sns)）。

## 4. 「子どもとSNS」を足した

そこで、合意点マップに「子どもとSNS」を足しました。手順はこうです。

1. **国会の発言を集める**：国会会議録検索システムのAPIで「SNS 年齢制限」「子ども SNS」などを含む発言を集めた（110件。2020〜2023年は年2〜6件、2026年は7月までに38件と急増）
2. **ニュースへの反応を集める**：オーストラリア・英国・フランス・スペインの16歳・15歳未満のSNS禁止と、カナダの子どものSNS制限法案のニュース5本に寄せられたYahoo!ニュースのコメント26件
3. **論点を立てる**：国会の発言24件とニュース5本を材料に、ローカルLLM（gemma4:12b）が「賛否を押せる1文」に言い換えた。14の論点のうち、7つは国会、7つはニュースの反応から
4. **反応の賛否を読み取る**：ニュースのコメント1件ずつについて、各論点に賛成か反対か触れていないかを読み取った（23件×14論点＝322回。賛成90・反対55・触れていない177。ローカルLLMによる推定で、精度は75〜85%）

できた論点には、立場がよく散らばっています。

| 立場 | 論点の例 |
|---|---|
| 禁止に賛成 | 16歳未満のSNS利用を法律で禁止すべきだ |
| 規制に懐疑 | SNS利用の規制は実効性に乏しく無意味である／SNS禁止は事実上の言論統制につながる恐れがある |
| 家庭に任せる | 政府主導の一律な規制よりも、親の判断を重視すべきだ |
| 事業者に求める | プラットフォーム事業者の役割を再定義し保護措置を求めるべきだ／アプリの設計改善で解決を図るべきだ |
| 教育 | 子供のインターネット利用におけるリテラシー向上を最優先すべきだ |
| 居場所 | SNS利用制限は子供の居場所や相談ツールとしての利便性を損なう |

国会の発言だけで作ったときには、「規制は無意味」「言論統制につながる」「オールドメディアが規制を求めている」のような、規制への疑いや反発の声は出てきませんでした。ニュースの反応を足して、はじめて国会の外の声が入りました。

ニュースのコメントから読み取った賛否には、はっきりした傾向が出ました。

- 「16歳未満のSNS利用を法律で禁止すべきだ」に触れた12件のうち、**9件が賛成**
- 一方で「SNS利用の規制は実効性に乏しく無意味である」は、**賛成8・反対8で真っ二つ**

禁止には賛成が多いのに、効くかどうかは疑っている。チームみらいの広聴本部が219人の回答から見つけた「年齢制限をかけても抜け道が出る」という共通の心配と、同じ形がネットの声からも出ました。ただし、これは機械の読み取りによる推定で、人が押した票ではありません。画面では、人の票と分けて、元のコメントの要点を添えて出しています。

## 途中でつまずいたところ

- **全角の「ＳＮＳ」**：Yahoo!ニュースの題名は「ＳＮＳ」のように全角で、半角の「SNS」で探しても当たらなかった。照らす前に全角・半角をそろえるようにした
- **空白入りの語**：「子ども SNS」のような語を、空白込みのまま題名と比べていた。空白で区切って、それぞれが含まれているかで見るようにした
- **コメント欄のURL**：記事のURLを渡すとコメントを取りに行かず、コメント欄のURL（末尾が /comments）を渡す必要があった
- **集まる数**：1記事から取るコメントは上位8件までで、5本で26件だった。数千件を集めるには、記事を日々溜めるか、取る件数を増やす必要がある

## まだ足りないところ

正直に書くと、合意点は**人が賛否を押してはじめて**出ます。合意点マップは、3問以上押した人が8人未満のうちは意見グループを作らず、作り物の票も画面に出しません。先に公開していた「消費税減税」も、ニュースの反応176件から賛否を読み取れている一方で、人が押した票は2人・15票です。

論点は人を待たずに立ちます。でも合意点は、押す人が集まって初めて見えます。この記事を読んだ方が、「子どもとSNS」の論点に賛否を押してくれるとうれしいです。1問10秒、登録は要りません。

- [子どもとSNSの論点に賛否を押す](https://kurage.exbridge.jp/kconsensus.php/t/kodomo-sns/?ref=vibeblog_kconsensus-sns)

## 自社・自治体・議員事務所に置く

合意点マップは、PHPとPythonで動き、判定は手元のLLMで行うので、意見を外部のAIに送りません。読み取りの精度（75〜85%）と誤読も画面に出します。自治体のパブリックコメントや住民アンケートの自由記述、議員事務所に届いた声をCSVで入れれば、誰も投票する前から意見グループが出ます。

## よくある質問

### Pol.isとは何ですか？

Colin Megill らが開発した、意見に賛否を押してもらい、意見の分かれ方と、立場の違う人どうしが賛成する点を見つけるオープンソースの仕組みです。台湾の vTaiwan で、オードリー・タンさんが政策づくりに使ったことで知られています。

### 合意点マップとPol.isの違いは何ですか？

計算の筋は同じで、当社がMITライセンスで自前に実装しました。違いは、意見の投稿を待たずに、国会の発言とニュースへの反応から論点を立てることです。Pol.isは投稿する人が集まらないと合意点が出ませんが、合意点マップは人を待たずに論点の地図が作れます。

### デジタル民主主義2030は活発ですか？

2026年10月時点では、動いているのは広聴AIだけで、直近30日のコミットの74%は1人です。Slackの登録は1,600人を超えますが、書き込む人は月16人ほどでした。
