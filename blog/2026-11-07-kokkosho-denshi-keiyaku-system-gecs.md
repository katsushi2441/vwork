名古屋でAIシステムの開発をしている小嶋です。

「電子契約システム 国土交通省」と検索する人が、毎月それなりにいます。公共工事を受ける建設会社や、コンサル業務を受ける会社の担当の方だと思います。国土交通省の電子契約システム（正式には「電子契約システム（工事・業務）」、略して GECS）について、受注者の側が何を準備すればいいかを、公式のFAQと準備の手順のページをもとにまとめました。

## 電子契約システム（GECS）とは

| 項目 | 内容 |
|---|---|
| 何をするものか | 紙で行っていた契約の手続きを、パソコンからインターネットを通して行う。制度の上では紙の手続きと同じ扱い |
| できる手続き | 契約、検査・請求、利用者の管理、発議など |
| 使える時間 | メンテナンスの期間を除いて、24時間365日 |
| 共同企業体・支店 | 共同企業体や支店単位の契約でも使える |
| 原本 | 電子のデータが原本。PDFで出した契約書は控え |
| 受注者のメリット | 印紙代・移動の費用・郵送の費用が減る（公式のFAQの説明） |

紙で始めた案件を、発注者が途中から電子契約システムに登録することもできます。登録したあとは、紙でも電子でもやり取りできると説明されています。

## 受注者が準備するもの

準備の手順は、公式のページで次の順番になっています。

1. パソコンとインターネットの環境を確かめる
2. 電子証明書を取る
3. ICカードとICカードリーダーを設定して、動くか確かめる（ICカード形式の場合）
4. 電子契約システムのプラグインを入れる
5. ブラウザーを設定する
6. システムにつながるか確かめる
7. 利用者登録をする
8. 端末の設定を確かめる

パソコンは Windows 11、ブラウザーは Microsoft Edge か Google Chrome の最新版が推奨されています。

## 電子証明書の選び方

使えるのは、システムに対応した認証局が出す電子証明書です。公式のページに並んでいるのは次の6つです。

- NTT西日本（e-Probatio PS2）
- 三菱電機デジタルイノベーション（DIACERT-PLUS）
- 帝国データバンク（TDB電子認証サービスTypeA）
- トインクス（TOiNX電子入札対応認証サービス）
- 日本電子認証（AOSign）
- 電子認証登記所（商業登記に基づく電子認証制度）

形は、ICカード形式とファイル形式の2つです。ファイル形式で取れるのは、電子認証登記所（商業登記に基づく電子認証制度）だけです。ICカード形式は、PIN番号を何度か間違えるとロックされます。ファイル形式はロックされません。

電子入札で使っている証明書と同じものである必要はありません。契約の権限を持つ人の証明書であれば使えます。値段やサービスの中身は認証局ごとに違うので、比べて選ぶよう案内されています。

## 利用者登録の手順と、先に知っておきたいこと

電子証明書とパソコンの準備ができたら、ポータルサイトのトップページの「利用者登録」から登録します。

- 登録が終わると、受注者番号がメールで届く。この番号を発注者に伝えると、案件の受注者として設定される
- 登録した「商号又は名称・氏名・住所」は、あとから直せない
- 振込先の口座は、最大10件まで登録できる
- 代表者から委任を受けた代理人が、自分の名前の証明書で登録する運用が前提になっている（年間委任状で、代表者から代理人へ契約の権限が委任されていること）

商号や住所をあとから直せないのは、見落としやすい点です。登録の前に、登記どおりの表記を確かめておくのが安全です。

## いちばんつまずく所：電子証明書の更新

電子証明書には有効期限があります。ここで困る人が多いようで、公式のFAQにも何度も出てきます。

- 使えるのは、有効期限まで11日以上残っている証明書。期限まで10日以下の証明書は使えない
- 期限が切れた、または代表者が替わって新しい証明書にしたときは、「電子証明書を更新する」から手続きする
- **このとき、間違えて「利用者登録」をやり直すと、古い証明書の情報や、それまでの調達案件が引き継がれない**
- 新しい証明書でログインしようとして「利用者登録されていません」と出たら、それは更新の手続きがまだ、という意味

期限が近づいたら、余裕を持って新しい証明書を取り、「更新」で切り替える。登録をやり直さない。この2つを担当者の間で引き継いでおくと、慌てずに済みます。

## 請求書の出し方

請求書は2通りあります。

- デジタルインボイス：日本の規格（JP PINT）に対応した会計ソフトなどから、Peppol ネットワークで送る。特別な手続きは要らないが、送る内容に「GECS」と入れる必要がある。システムへの反映はすぐではなく、定期的に取り込まれる
- それ以外：システムに請求書を登録する。適格請求書として出すときは、チェックボックスを選ぶ

どちらで出すかは、前もって発注者に確かめるよう案内されています。

## 民間の工事の電子契約は、別に考える

GECS は、国土交通省などの公共の発注者との契約のための仕組みです。施主や元請けとの民間の工事の契約を電子にするなら、別の電子契約の仕組みが要ります。

建設業法では、工事の請負契約を電子で結ぶには、相手方の承諾を得たうえで、国土交通省のガイドラインにある3つの技術的な基準（見読性・原本性・本人性）を満たす必要があると解説されています。

民間の契約の電子化は、月額のクラウドサービスを使うのが一般的ですが、自社のサーバーで持つ方法もあります。当社では、電子契約のオープンソース「DocuSeal」を日本語で使うための導入キットを出しています。工務店の電子契約については、別のページにまとめました。
