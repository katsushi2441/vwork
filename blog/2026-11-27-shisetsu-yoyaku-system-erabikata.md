名古屋でシステム開発をしている、株式会社エクスブリッジの小嶋です。

公民館や体育館、貸会議室の空きを電話で聞かれて、紙の台帳を見ながら答えている。社内の会議室は入口のホワイトボードに名前を書いて押さえている。どちらも、施設予約システムを探し始めるきっかけとしてよく聞く話です。ところが「施設予約システム」で調べると、自治体向けの大きなものから、サロンの予約、社内の会議室予約まで同じ言葉で並んでいて、どれが自分のところに合うのかが分かりにくいと思います。

この記事では、選ぶときに見るところを順番に書き、そのあとで、当社が Kurage App Store で出している2つのシステムをどう使い分けるかを書きます。

## 施設予約システムの選び方

### 1. だれが予約するのか（外の利用者か、社員か）

最初に分けておきたいのは、予約を入れるのが施設の外の人なのか、社内の人なのかです。公民館や貸室、コワーキングのように、外の利用者が自分のスマートフォンから空きを見て押さえるなら、利用者に毎回ログインしてもらう作りは向きません。名前と連絡先を入れれば予約でき、確認のメールと、自分で取り消すための手段が届く形が使いやすいはずです。

反対に、社内の会議室や社用車なら、だれが押さえたのかが分かることのほうが大事です。社員のアカウントでログインして予約し、ほかの人の予約も名前と目的まで見えるほうが、「この時間、譲ってもらえますか」と声をかけやすくなります。会議室予約システムを探している方の多くは、こちらだと思います。

### 2. 部屋ごとに空きを数えるか、予約の単位と受付の期間

部屋が1つなのか、大会議室・小会議室・社用車のように複数あって、それぞれ別々に空きを数えたいのかで、合うシステムが変わります。あわせて、何分刻みで予約できるか、貸出の単位（1時間・2時間・半日など）、何日先まで受け付けるか、直前の予約をいつ締め切るかも確かめておくと、入れてから困りません。毎週の定例のような繰り返しの予約を入れたいなら、その機能があるかも見てください。

### 3. 同時に押されたときに、重ならないか

予約の仕組みでいちばん困るのは、2人がほぼ同時に同じ時間を押したときです。画面を開いた時点では空いていても、確定するまでのあいだに別の人が押さえているかもしれません。確定の瞬間にもう一度空きを確かめて、先の1人だけを通す作りになっているかは、デモで2つの画面から同じ枠を押してみると確かめられます。

### 4. 予約が入ったあとの扱い

運用が始まると、取り消し、電話や窓口で受けた予約の書き足し、間違えて取り消した予約の戻し、月ごとの利用実績の集計が必ず出てきます。管理する側の画面で、日ごとの一覧を見て、名前や電話番号で探し、Excel で開ける形で書き出せるかを見ておくと安心です。

### 5. 入っていない機能を、先に確かめる

抽選の申込、利用料の決済、複数の施設をまたいだ検索、利用者登録の審査といった機能は、システムによって入っていたりいなかったりします。必要なものが入っていないと分かるのが導入のあとだと手戻りが大きいので、製品の説明で「できないこと」が書かれているかを見て、書かれていなければ問い合わせてください。

### 6. クラウドの月額か、自社のサーバーに置くか

クラウドの予約サービスは、申し込めばすぐに使え、サーバーの面倒を見なくて済むのが良いところです。その代わり、使い続けるあいだ月額の利用料がかかり、予約の記録はそのサービスの中に置かれます。自社のサーバーやレンタルサーバーに置く形（オンプレミス）は、買い切りで月額がかからず、記録も自分のところに残りますが、設置と更新は自分たちでやることになります。小さな施設1つのために大きなシステムを入れるのが重い場合や、設定を自分のところに合わせて直していきたい場合は、自社サーバーに置く形も候補に入れてみてください。

## 当社の2つのシステムの分け方

当社では、施設の予約に使えるシステムを2つ出しています。上の1番の「だれが予約するのか」で分けると分かりやすいです。

### 外の利用者がWebで予約する施設には、Kurage 予約・受付（kreserve）

[Kurage 予約・受付（kreserve）](https://kappstore.exbridge.jp/app.php?id=362c94ab4e1384f2#ref=vibeblog-shisetsu-yoyaku)は、予約ページと管理画面からなる予約管理システムです。もとはサロンやクリニックの予約向けに開発したもので、メニューを部屋や設備に置き換えると、施設予約として使えます。利用者は、部屋を選び、日を選び、時間を選び、名前と電話番号を入れる、の4つの手順で予約でき、ログインはしません。メールアドレスを入れた人には確認のメールが届き、完了の画面とメールに出る取り消し用のURLから、決めた期限までなら自分で取り消せます。日の選び方の画面では空き具合が○△×で見え、休館日は自動で外れます。

管理画面では、日ごとの予約一覧、名前や電話番号での検索、取り消しと戻し（戻すときは枠が空いているかを確かめ直します）、電話や窓口で受けた予約の手動の追加、月ごとのCSVの書き出しができます。空き枠の判定と予約の書き込みは、台帳のファイルに同じ排他ロックをかけた中で行うので、2人が同時に押しても確定するのは先の1人だけです。この動きを含む25項目の検証スクリプトが付いています。

PHP 5.6〜8.3 が動くレンタルサーバーに FTP で置けば動き、データベースは要りません。メニュー（部屋）・営業時間・休館日・枠の刻み・受付の期間・取り消しの締切は設定ファイル1枚にまとまっていて、同梱のAI向けの設計マニュアルを Claude Code などに読ませて変えてもらう使い方を想定しています。

一つ、選ぶ前に知っておいていただきたいことがあります。同じ時間に受けられる件数の設定は、施設全体で1つの数です。部屋を2つ登録して件数を1にすると、大会議室が埋まっている時間は小会議室も押さえられません。部屋が1つの施設や、同じ部屋がいくつかあってどれかが空いていればよい場合はそのまま使えますが、部屋ごとに別々に空きを数えたい場合は、同梱の改造レシピ（スタッフ指名制にするレシピと同じ考え方）で手を入れることになります。抽選、利用料の決済、複数施設の横断検索、利用者登録の審査も入っていません。

### 社内の会議室・社用車・備品には、Kurage Vibe Groupware の施設予約

社員が使う会議室予約なら、[Kurage Vibe Groupware](https://kappstore.exbridge.jp/app.php?id=fe433e5061769cba#ref=vibeblog-shisetsu-yoyaku) の施設予約のほうが合います。メッセージ・掲示板・ToDo・ワークフロー・共有スケジュールと一緒に入った社内グループウェアで、ログインは社員番号とパスワード、Google Workspace、Microsoft 365 から選べます。

施設は管理者が名前・分類（会議室・社用車・備品など）・説明を付けて登録し、施設ごとに別々に空きを数えます。予約は1日か1週間の空き表から入れ、同じ施設の同じ時間に2つの予約は入りません。重なったときは、相手の時間と名前が出ます。毎日・平日・毎週の繰り返し（30回まで）は、1日でも重なる日があれば1件も入れない作りです。予約は全員に見え、直したり消したりできるのは、予約した本人と同じ部署の責任者と管理者です。予約を共有スケジュールに載せておけば、iPhone や Android の標準カレンダーにも出ます。

新着をメールやスマートフォンの通知で知らせる機能はなく、予約できるのは社内のアカウントを持つ人だけなので、外の利用者に開く施設予約には向きません。

- [Kurage Vibe Groupware のデモ](https://proto.exbridge.jp/kvgw/#ref=vibeblog-shisetsu-yoyaku)
- 機能の詳しい説明：[グループウェアをオンプレミスで作った（Kurage Vibe Groupware）](https://exbridge.jp/vibeblog/2026-11-10-kvgw-groupware-onpremise-workflow-keijiban.html#ref=vibeblog-shisetsu-yoyaku)

どちらも買い切りで、人数や予約の件数が増えても月額の利用料はかかりません。ソースコードは MIT ライセンスで付き、自社に合わせて手を入れられます。まずデモで、予約を入れる、管理する側で確かめる、取り消す、までを通して、ご自分の運用に合うかを確かめてください。合うか分からないときや、足りない機能を足したいときは、[Kurage App Store](https://kappstore.exbridge.jp/#ref=vibeblog-shisetsu-yoyaku) の商品ページからご相談いただけます。

## よくある質問

**Q. 公民館や貸会議室で、利用者に Web から予約してもらうにはどちらを選べばいいですか？**

Kurage 予約・受付（kreserve）です。利用者はログインせずに、部屋・日・時間・名前と連絡先の4つの手順で予約できます。部屋ごとに別々に空きを数えたい場合は手を入れる必要があるので、デモで動きを確かめたうえでご相談ください。

**Q. 社内の会議室と社用車をまとめて予約できるシステムはどれですか？**

Kurage Vibe Groupware の施設予約です。会議室・社用車・備品を分類して登録でき、施設ごとに空き表が出ます。同じ施設の同じ時間に2つの予約は入りません。

**Q. 利用料の決済や抽選の申込はできますか？**

どちらのシステムにも入っていません。Kurage 予約・受付は1つの施設の空き枠を見せて押さえてもらう範囲のシステムです。必要な場合は、AIエージェントで足すか、当社にご相談ください。

**Q. データベースのあるサーバーが必要ですか？**

要りません。どちらも PHP が動くレンタルサーバーに FTP で置けば動き、予約の記録はサーバーの中のファイルに入ります。動作する PHP は、Kurage 予約・受付が 5.6〜8.3、Kurage Vibe Groupware が 7.0 以上（8.x 推奨）です。Kurage Vibe Groupware は HTTPS で使ってください。
