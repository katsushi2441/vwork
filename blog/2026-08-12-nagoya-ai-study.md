名古屋・愛知の経営者、個人事業主、副業・起業準備中の方向けに、**LINEオープンチャットの無料コミュニティ「名古屋AI経営勉強会」**を始めました。

👉 **[名古屋AI経営勉強会（参加無料）](https://kurage.exbridge.jp/nagoya-ai-study.php)**

## どんな取り組み？

オープンチャットの中で、**AI経営・バイブコーディング・AIエージェント（Codex・Claude Code など）の質問に、ゆるく答えます。**

- 「この作業、AIで楽にならない？」という素朴な相談
- Codex・Claude Code の始め方（導入でつまずくポイントの解消）
- 業務のどこにAIを入れると効果が出るか
- 実際に自社で運用している事例・失敗談の共有

回答するのは、AIで業務システムを実際に開発・運用している名古屋の会社（株式会社エクスブリッジ）の運営者です。教科書的な話ではなく、**実運用の経験ベース**で答えます。

## こんな方へ

- ChatGPTは使っているけれど、その先（AIに業務を実行させる）へ進みたい経営者の方
- 副業や起業準備でAIを学びたい方
- 初心者大歓迎。**見ているだけの参加もOK**です

## 参加方法（無料・匿名OK）

[紹介ページ](https://kurage.exbridge.jp/nagoya-ai-study.php)で𝕏（旧Twitter）アカウントでログインすると、LINEオープンチャットの参加リンクとQRコードが表示されます（荒らし・スパム対策のためXアカウントが必要です）。オープンチャットなので普段のLINE名は表示されず、ニックネームで参加できます。

- 参加無料・出入り自由
- 宣伝・営業・勧誘・マルチは禁止（即退会）の、安心して質問できる場にしています
- 不定期でオンライン交流会も開催予定
