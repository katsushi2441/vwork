名古屋でAIシステム開発の会社をやっています。**音声をサーバーの外に出さないAI議事録システム「Kurage AI MOM」**を公開しました。録音（wav/mp3/m4a）をアップすると、自社サーバー内のWhisper（whisper.cpp）が文字起こしし、AIが議事録の下書き（概要・決定事項・ToDo・課題・次回）を作り、**人が承認したものだけが確定議事録になる**、1ファイルPHP+SQLiteの買い切りシステムです。

なぜ作ったのか——「議事録AIはみんなCopilotでやるのでは？」という仮説を検索データで検証したら逆だった、というリサーチの一部始終は**noteに書きました**。「ボイスレコーダー 文字起こし」月9,900回という空白を見つけるまでの話です。

- [議事録AIは「みんなCopilotでやる」と思ったら、検索データは逆だった（note）](https://note.com/tokoname/n/nf005302f8d01)

この記事では、**入手と構築の選択肢を全部並べて、どれを選ぶべきかを作った本人が仕分けします**。

## まず触る（無料・3分）

デモ環境に録音をアップすると、文字起こしとAI下書きの品質をそのまま確かめられます。

- デモ: [https://proto.exbridge.jp/kaimom/](https://proto.exbridge.jp/kaimom/)

実測値だけ先に書いておくと、8コアCPUのサーバー（GPUなし）で24秒の録音を文字起こしし、**決定事項・金額・日付・人名まで正しく認識**（誤りは同音異義語1か所）。処理時間は同じ録音・同じ設定でも**17.7秒〜93.0秒**とサーバーの状況で大きくばらつきました（6回実測・2026-09-01追記）。導入前にご自身のサーバーでの実測をおすすめします。

## 選択肢1: GitHub — 無料（自力で構築できる人向け）

ソースコードはMITライセンスで公開しています。

- [https://github.com/katsushi2441/kaimom](https://github.com/katsushi2441/kaimom)

READMEに設置手順があります。whisper.cppのビルドとPHPの設定が自力でできる方なら、これで十分です。**エンジニアがいる会社はここで止めるのが正直おすすめ**——かかるのはVPS代（月1,000円前後）だけです。

## 選択肢2: Kurage App Store — 完成品zip・買い切り55,000円（税込）

完成品のzipと商品ページ。動作確認済みの一式をそのまま落とせます。

- [商品ページ](https://kappstore.exbridge.jp/app.php?id=cd1eda3248c87920)

GitHubと中身は同じです。差は「動く状態の確認済みパッケージを、対価を払って正規入手する」こと。会社の経費で買って、改造して社内配布しても構いません（MIT）。

## 選択肢3: Brain — 導入手順書つき・55,000円（税込）

**サーバー構築の全手順書＋本体**のセットです。本体と同一価格なので、実質「手順書がおまけに付く買い方」です。

- [Brainの記事](https://brain-market.com/a/bxkDOyYjMgoTZsNWa0JXY)

有料部に書いたもの: VPSの選び方（共用レンタルサーバーで動かない理由）、whisper.cppのビルドコマンド全部、構築中に実際に踏んだphp.iniの罠、workerのsystemdユニットの実物、要約AI3択（自社Ollama/OpenAI互換/なし）の設定、トラブルシューティング一覧、カスタマイズのAI用プロンプト集、そして**Claude Codeに設置作業そのものを任せるSKILL.md全文**。メールでの導入質問3か月つき。

**「エンジニアはいないが、AIツール（Claude Code等）は使える」という会社はこれが最短**です。SKILL.mdを渡せばAIが設置します。

## 選択肢4: バイブプロトタイピング — 自社仕様に作り込む・税込110,000円〜

「うちの会議テンプレの項目に合わせたい」「承認フローを2段にしたい」「基幹システムに繋ぎたい」——既製品では足りない場合の受託開発です。最短1営業日で動くデモを作ってから話を進めます。

- [バイブプロトタイピング](https://kurage.exbridge.jp/vibe-prototype.html)

## 選択肢5: バイブOSSカスタマイズ — 構築ごと任せる・税込110,000円〜

サーバーの用意からwhisper.cppの構築、本体設置、運用設計（承認ルール・バックアップ）までを当社が代行します。kaimomに限らず、OSSの選定・日本語化・自社サーバー構築全般の入口です。

- [バイブOSSカスタマイズ](https://kurage.exbridge.jp/vibe-oss.html)

## 仕分けの早見表

| あなたの状況 | 選ぶべき経路 | 費用 |
|---|---|---|
| エンジニアがいる | GitHub | 無料 |
| 会社として正規入手したい | kappstore | 55,000円 |
| エンジニア不在・AIツールは使える | Brain（手順書+SKILL.md） | 55,000円 |
| 自社仕様に改造したい | バイブプロトタイピング | 110,000円〜 |
| 構築ごと丸投げしたい | バイブOSS | 110,000円〜 |

Whisperそのものの解説（無料で文字起こしする方法、クラウドSaaSとの使い分け）は[解説ページ](https://exbridge.jp/whisper-mojiokoshi.php)にまとめました。「録音を外部クラウドに上げられない」規定のある会社の方は、まずデモからどうぞ。
