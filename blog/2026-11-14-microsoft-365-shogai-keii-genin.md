名古屋でAIシステムの開発をしている小嶋です。

日本時間の11月13日未明から、Microsoft 365 で世界規模の障害が起きました。Outlook でメールが読めない、Teams の予定が開けない、という状態が丸一日以上続き、仕事が止まった会社も多かったと思います。

共同通信（47NEWS）によると、個人向けのサービスは、日本時間の11月14日午後1時10分に完全に復旧しました。始まりから**約36時間**です。

Microsoft が途中で出してきた説明と報道をもとに、何が起きて、なぜこれほど長引いたのかをまとめます。

**この記事は、11月14日午後の時点の情報に基づいています。** Microsoft は事後の報告（PIR）を出すとしていて、最初の引き金の詳しい中身はまだ分かっていません。

先にまとめます。

- **期間**：日本時間11月13日 1時17分に始まり、個人向けは14日 13時10分に完全復旧。会社向けは、たまったメールの処理を確かめてから解決とする方針です
- **止まったもの**：Outlook（Web・アプリ・スマホ）を中心に、Teams の予定表や会議の予約、SharePoint、Microsoft 365 Copilot、Defender XDR、Intune、Power BI など。ChatGPT や Claude の Microsoft 365 コネクタにも影響が出ました
- **原因**：Microsoft は「以前のネットワークの能力増強の作業での問題が、最近のネットワークの変更のあとで表に出たもの」と説明しています。攻撃や AI・エージェントとは関係のない技術的な問題だとしています
- **広がった仕組み**：多くのサーバーが自動の点検（ヘルスチェック）に落ちてサービスから外され、残ったサーバーに負荷が集まって、さらに止まる、という連鎖が起きました
- **長引いた理由**：一度回復しかけたあと、戻したサーバーが再び応答しなくなりました。そのあとも、止まっている間にたまったメールと処理を片づけるのに時間がかかりました

## なぜ長引いたのか

ここからは、Microsoft の説明をもとにした、システムを作る側としての当社の見方です。最初の引き金の詳細は、事後の報告を待つ必要があります。

### 1. 「前に仕込まれていた問題」と「最近の変更」の組み合わせだった

最近の変更だけが悪かったのなら、それを元に戻せばすぐに直ります。今回の説明は、以前の能力増強の作業に問題が潜んでいて、それが最近の変更をきっかけに表に出た、というものでした。

どの変更が本当の原因なのかを見分けるのは、こういうときがいちばん難しくなります。実際に、ネットワークの設定の変更を巻き戻し始めたのは、障害が始まってから約9時間後でした。

### 2. サーバーを守るための点検が、障害を広げた

ヘルスチェックは、調子の悪いサーバーを自動で外して、利用者に迷惑をかけないための仕組みです。

ところが今回は、安全な接続を張る処理が詰まったサーバーが、次々に「調子が悪い」と判定されて外されました。外れた分の仕事が残りのサーバーに回り、それも詰まって外される。守るための仕組みが、障害を連鎖させる側に回ってしまいました。

Microsoft が最初に「負荷が増えた」と説明し、あとで取り消したのも、外から見ると、この連鎖がアクセスの増加のように見えたからだと思います。

### 3. 戻そうとすると、また止まった

7時58分に一部で回復したあと、8時59分には戻したサーバーが再び応答しなくなりました。

サービスが止まっている間、世界中の Outlook や Teams は、つながるまで接続をやり直し続けています。サーバーを戻した瞬間に、その再接続が一斉に押し寄せます。暗号化した接続を張る処理は重いので、戻したばかりのサーバーがすぐにあふれてしまいます。

設備を切り離して再起動し、少しずつ戻すやり方に切り替えたのは、この押し寄せを避けるためだと考えられます。午後に裏側のサーバーへの呼び出しが急に増えたのも、止まっていた間にたまった処理が流れ込んだものと見られます。

### 4. つながってからも、たまったメールの片づけが残った

画面が開けるようになっても、止まっていた間に届くはずだったメールを配り終えるまでは「解決」とは言えません。Microsoft はメールの再配達の期限を48時間に延ばし、たまったメールが片づいたのを確かめてから解決とする方針を示しました。

個人向けが先に完全復旧を発表し、会社向けがそのあとになっているのは、会社の方がメールの量も、つながっている仕組みも多いからだと思います。

## 届かなかったメールは、どうなるのか

送る側のメールサーバーは、相手が受け取れないとき、しばらく時間をおいて送り直します。今回、Microsoft は再配達の期限を48時間に延ばしているので、障害の間に送られたメールの多くは、遅れて届くことになります。

気をつけたいのは、届いていないと思って同じメールを何度も送り直すことです。あとから全部届いて、相手の受信箱に同じメールが並ぶことになります。急ぎの用件は、電話など別の手段で「メールを送りました」と伝えるほうが確実です。

## AIもいっしょに止まった

今回は、ChatGPT や Claude の Microsoft 365 コネクタにも影響が出たと報じられています。Microsoft 365 Copilot も使えない時間がありました。

メールや予定表、社内の文書を AI に読ませて仕事を回している会社では、メールが止まると同時に AI の仕事も止まります。AI を業務に組み込むほど、その AI がどこのサービスにつながっているかを把握しておく必要があります。

## 1社に頼るリスクは、国会でも

1つのクラウドに頼ることの危うさは、国会でも取り上げられてきました。

2025年11月26日の衆議院厚生労働委員会で、尾辻かな子議員は、国のデータベースのクラウド基盤が1社に集中していることについて、次のように述べています。

> このクラウド基盤が一社に集中しているという現状は、今までベンダーロックインが駄目だと言っていましたけれども、ただベンダーロックインがクラウドロックインに変わっただけではないかという印象を受けるわけです。

尾辻議員は、そのリスクの一つとして「障害時のシステム停止」も挙げています。国のシステムでも会社のシステムでも、1社に全部を任せていれば、その1社が止まったときに全部が止まるのは同じです。

## 会社として備えたいこと

- **緊急の連絡手段を決めておく**：メールも予定表もチャットも同じ会社のサービスなら、すべて同時に止まります。電話や別のチャットなど、障害のときに使う手段と連絡先を、紙でも持っておくと安心です
- **状況を確かめる場所を知っておく**：Microsoft 365 の管理センターのサービス正常性と、Microsoft の公式の障害情報です。今回の障害は、管理センターで EX1550543 などの番号で出ていました
- **メールの再送は慌てない**：障害の間のメールは遅れて届きます。同じメールを何度も送り直さないよう、社内で伝えておきます
- **自社のシステムの「外す条件」と「戻す速さ」を見直す**：ヘルスチェックで外す条件が厳しすぎないか、止まったあとに一斉に戻して再び落ちないか。今回の障害は、規模にかかわらず、どのシステムにも当てはまる教訓です

## よくある質問

### Microsoft 365の障害はいつからいつまででしたか？

日本時間の2026年11月13日1時17分に Outlook の障害として始まりました。共同通信によると、個人向けのサービスは11月14日午後1時10分に完全に復旧しています。会社向けは、たまったメールの処理が終わったのを確かめてから解決とする方針が示されていました。

### 障害の原因は何ですか？

Microsoft は「以前のネットワークの能力増強の作業での問題が、最近のネットワークの変更のあとで表に出たもの」と説明しています。多くのサーバーが自動の点検に落ちて外され、残ったサーバーに負荷が集まったこと、暗号化した接続を張る処理があふれたことも説明されています。最初の引き金の詳細は、事後の報告を待つ必要があります。

### サイバー攻撃だったのですか？

Microsoft は、サイバー攻撃や AI・エージェントとは関係のない技術的な問題だと説明しています。悪意ある攻撃によるものだという兆しはない、としています。

### 障害の間に送られたメールは届きますか？

送る側のメールサーバーは時間をおいて送り直すので、多くは遅れて届きます。Microsoft は再配達の期限を48時間に延ばしました。同じメールを何度も送り直すと、あとで重複して届くので注意してください。

### Teamsも使えなかったのですか？

障害の初めは、Teams の予定表や会議の予約などにも影響が出ていました。13日の朝の時点では、影響はメールとやり取りする機能に絞られ、Teams のチャットとオンライン会議はおおむね使える、と説明されています。

### 同じような障害に、会社はどう備えればよいですか？

メール・予定表・チャットが同じ会社のサービスなら、障害のときに使う別の連絡手段を決めておくことです。状況は Microsoft 365 の管理センターのサービス正常性で確かめられます。自社でシステムを持っている場合は、点検でサーバーを外す条件と、止まったあとに戻す速さを見直しておくと、同じ型の連鎖を防ぎやすくなります。
