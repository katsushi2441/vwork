名古屋でAIシステムの開発をしている小嶋です。

11月8日の深夜1時すぎ、名古屋でもかなり揺れました。横揺れが長く続いて、怖い思いをした方も多いと思います。当社は名古屋の会社で、活断層や南海トラフの揺れの想定をもとにした防災のシステムを作っているので、今回の地震が「想定していた地震」だったのかを、データで確かめました。

## 今回の地震（気象庁の発表）

| 項目 | 内容 |
|---|---|
| 発生 | 2026年11月8日 1時04分 |
| 震源 | 静岡県西部（北緯34.9度・東経137.7度、浜松市の北のあたり） |
| 深さ | 約40km |
| 規模 | マグニチュード5.7 |
| 震度5強 | 愛知県 知多市 |
| 震度5弱 | 愛知県 瀬戸市・半田市・刈谷市・豊田市・東海市・みよし市・東郷町・新城市、長野県 売木村、岐阜県 恵那市、静岡県 浜松市浜名区 |

最初の緊急地震速報では、震源は「愛知県東部」と推定されていて、NHKの速報も「愛知県付近で地震」でした。その後の気象庁の発表で、震源は「静岡県西部」になっています。いちばん強く揺れたのは震源から離れた愛知県西部の知多市だったので、「愛知の地震」という印象を持った方も多いと思います。

## 活断層の地震だったのか

当社で作っている活断層の判定のシステムで、震央の座標を調べました。使ったのは、防災科学技術研究所の J-SHIS（地震ハザードステーション）が公開している主要活断層帯のデータです。

| 震央から近い主要活断層帯 | 震央からの距離 |
|---|---|
| 伊那谷断層帯南東部 | 約33km |
| 恵那山−猿投山北断層帯 | 約51km |
| 猿投−高浜断層帯 | 約55km |
| 屏風山断層帯 | 約57km |
| 赤河断層帯 | 約61km |

**震央から30km以内に、主要活断層帯はありませんでした。** 国土地理院の都市圏活断層図も、震央のあたりは範囲の外でした。

もう一つは深さです。J-SHIS の主要活断層帯のモデルは、地表から数kmの浅いところで断層が動く地震を想定しています（断層の上端の深さは2km）。今回の地震の深さは約40kmで、活断層の想定とは深さがまったく違います。

このため、今回の地震は、地表近くの活断層が動いた地震とは考えにくい、というのが当社の見方です。

深さ40km前後で、東海地方の下に沈み込んでいるフィリピン海プレートに関係した地震の可能性がありますが、ここは推測です。気象庁がどのような地震だったか（発震機構など）を解説したら、それに従ってください。

## 「想定どおり」と言える部分もある

一方で、この地域が揺れやすい場所だということは、想定どおりです。

J-SHIS の2024年版では、震央のあたりは「30年以内に震度6弱以上の揺れに見舞われる確率」が31%で、全国でも高い区分に入っています。この確率を押し上げているのは、主に南海トラフの地震です。

つまり、

- 「近くの活断層が動く」という想定には、今回の地震は当たらない
- 「東海地方は強い揺れに見舞われやすい」という想定には、合っている

ということになります。名古屋市が公表している南海トラフ地震（最大クラス）の想定では、市内のほぼ全域が震度6弱以上（震度6弱が51.5%、6強が46.4%、震度7が1.3%）です。今回の震度5強・5弱より、ずっと強い揺れが想定されています。

## これから気をつけること

大きな地震のあと、揺れの強かった地域では、1週間ほどは同じくらいの揺れの地震に注意するよう、気象庁はふだんから呼びかけています。

- 寝る場所の近くに、倒れる家具や落ちる物を置かない
- 枕元に靴（スリッパ）と懐中電灯を置く
- 家族の連絡の方法と、近くの避難所までの道を確かめる
- 水・食料・携帯用のトイレを、最低3日分（できれば1週間分）

会社では、従業員と家族の安否を確かめる手順と、事業所や取引先の場所の揺れの想定を、この機会に確かめておくのがよいと思います。
