国会の会議録から質疑と政府答弁を集めて、ことがらごとに日付順で並べるページを28本公開しています。合計20,427件です。

90日間の検索表示回数は、**0回**でした。

- 一覧: <https://xb4g.com/giin/tracker?ref=vwork-tracker>

## 何が起きていたか

Search Console の URL 検査で、個別ページはこう出ていました。

```
Discovered - currently not indexed
last_crawl: まだクロールされていない
found_via_sitemap: https://xb4g.com/giin/sitemap.xml
```

Google は**見つけてはいるが、取りに来ていない**状態です。

技術的な不備を先に潰しました。サイトマップは407URL、lastmod は全件に付いていて、取得日は3日前、エラー0。一覧ページから個別ページへの内部リンクは HTML に28本出ていて、JavaScript で描いてもいません。一覧ページ自体は索引に入っています。**入口は入っているのに、中身が入っていない。**

## 題名を測ってみた

作ったページの名前は「国会トラッカー」でした。個別ページは「◯◯は国会でどこまで来たか」。

キーワードプランナーで測りました。

| 語 | 月間検索数 |
|---|---:|
| 国会トラッカー | **0** |
| 国会 質疑 検索 | 0 |
| 議員 発言 記録 | 0 |
| 国会議事録 検索 | 590 |

自分で付けた名前は、誰も検索していませんでした。

一方で、**扱っている中身のほうには需要がありました。**

| ことがら | 月間検索数 | 集めた発言 |
|---|---:|---:|
| 年収の壁 | 110,000 | 1,392件 |
| 不登校 | 74,000 | 2,392件 |
| 更年期 | 60,500 | 253件 |
| 取適法 | 60,500 | 1,301件 |
| 消費税減税 | 40,500 | 1,784件 |
| カスハラ | 33,100 | 713件 |
| OTC類似薬 | 22,200 | 495件 |
| こども誰でも通園制度 | 22,200 | 390件 |
| 自動運転 | 18,100 | 1,839件 |
| 公益通報者保護法 | 12,100 | 591件 |
| 特別養子縁組 | 9,900 | 739件 |
| 内密出産 | 2,900 | 213件 |

「年収の壁」を月に11万人が調べていて、そのことがらについて国会で1,392件の発言があり、うちはそれを全部持っている。なのに題名には「国会トラッカー」と書いてありました。

## 直したこと

28本すべてに実測値を持たせて、**題名の先頭を実際に検索されている語**にしました。

```json
{
  "key": "kisokojo-bukka-rendo",
  "name": "基礎控除の引き上げ・物価連動（年収の壁）",
  "seo_word": "年収の壁",
  "seo_volume": 110000
}
```

```
旧: 基礎控除の引き上げ・物価連動（年収の壁）は国会でどこまで来たか｜愛知の国会議員 発言ログ
新: 年収の壁は国会でどう議論されたか｜質疑と政府答弁
```

一覧ページも「国会トラッカー」から「国会議事録から、法案のいまを追う」に変えました。こちらは590の語に寄せています。

## サイト名の足し方も直した

共通の処理で、全ページの題名に「｜愛知の国会議員 発言ログ」を足していました。これで41字になります。

検索結果に出るのは全角30〜35字程度です。先頭に実測語を置いても、サイト名に押し出されて切れたら意味がありません。**題名が22字以上ならサイト名を足さない**ようにしました。いま23〜32字です。

## 学んだこと

3つあります。

**製品の名前は、機能の名前であって検索語ではありません。** 「国会トラッカー」は中で何をしているかを正確に言い表していますが、その言葉で探す人はいません。名付けた側は自分の言葉に愛着を持つので、ここは測らないと気づけません。

**題名を長くするのは、先頭を削ることと同じです。** サイト名やブランドを機械的に足す処理は、たいていどのサイトにもあります。それが一番大事な語を画面外へ押し出していないか、実際の文字数で見ないと分かりません。

**索引に入らない原因は、技術的な不備とは限りません。** サイトマップもリンクも正しいのに取りに来ないのは、Google がそのページを取りに行く価値を感じていないということです。題名はその判断材料の一つです。

題名だけで解決するとは思っていません。参照元が1本しかないのも効いているはずなので、そちらも手を付けます。
