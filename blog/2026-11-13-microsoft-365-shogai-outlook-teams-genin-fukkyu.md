名古屋でAIシステムの開発をしている小嶋です。

2026年11月13日、日本時間の未明から、Microsoft 365 で大規模な障害が起きています。メールが送れない、Outlook が開かない、Teams がおかしい、という声が朝から続いています。

Microsoft が公式に出している発表を、日本時間に直して読み直しました。報道とあわせて、何が起きていて、なぜ長引いているのかをまとめます。

**この記事は、11月13日15時30分の時点の情報です。** このあとの発表で内容が変わることがあります。

先にまとめます。

- **何が止まったか**：メールの Exchange Online のメールボックスにつながらなくなりました。Outlook（Web版・デスクトップ・スマホのアプリ）が使えず、AIの Copilot にも影響が出ています。報道では、Teams など複数のサービスにも影響が出ています
- **いつから**：日本時間の11月13日2時54分に、Microsoft が最初の調査開始を発表しました。15時台になっても、全面的な復旧は発表されていません
- **原因**：アクセスが急に増えたのではなく、**サーバーが自動のヘルスチェックに失敗して次々に使えなくなり、残りのサーバーに負荷が集中した**と Microsoft は説明しています。最近の変更との関係は見つかっていないとしています
- **なぜ長引いているか**：再起動して戻したサーバーが、**通信を受けるとまた応答しなくなる**ためです。昼には、効果が出ていると発表していた復旧策が「想定どおりに効いていない」と一転しました
- **サイバー攻撃ではない**と Microsoft は説明しています
- **政府にも影響**：尾崎官房副長官は、政府の情報システムの基盤である **GSS（ガバメント・ソリューション・サービス）にも支障が出ている**と会見で述べました

## 何が起きているか

Microsoft 365 は、メール（Exchange Online と Outlook）、チャットと会議（Teams）、ファイル共有（SharePoint と OneDrive）、AI（Copilot）をまとめて提供する、会社向けのクラウドサービスです。

今回止まったのは、メールの土台になっている Exchange Online です。報道によると、Outlook の Web 版、デスクトップアプリ、モバイルアプリのほか、MAPI、ActiveSync、REST という、ほかのメールソフトやシステムがメールボックスにつなぐための仕組みにも影響が出ました。

最初は、アメリカ大陸の利用者の問題として調査が始まりました。その13分後には、**どの地域の利用者にも影響が出うる**と Microsoft は発表しています。日本でも、朝から仕事のメールが使えない状態になりました。

Microsoft 365 管理センターでは、この障害は **EX1550543** と **MO1550821** という番号で案内されています。会社の情報システムの担当者の方は、この番号で経過を追えます。

## 原因：サーバーが「健康診断」に落ちて、次々に外れていった

大きなクラウドサービスでは、たくさんのサーバーに仕事を分けています。そして、それぞれのサーバーが正常に動いているかを、自動のヘルスチェック（健康診断のような確認）で絶えず確かめています。チェックに落ちたサーバーは、仕事の割り振りから外されます。

今回は、このヘルスチェックに失敗するサーバーが次々に出ました。外されたサーバーの分の仕事が残りのサーバーに回り、残りのサーバーにも負荷がかかって、さらに外れていく。アクセスが増えたわけではないのに処理が追いつかなくなったのは、こうした連鎖が起きたためです。

Microsoft は、ヘルスチェックの失敗が、サーバーの状態を処理する特定の部品から起きている可能性があるとしています。一方で、障害が始まった時刻と結びつく最近の変更は見つかっていないと説明しています。

## なぜ再起動で戻らなかったのか

障害の対応では、まず止まったサーバーを再起動して戻すことが多いです。今回も Microsoft は早い段階から再起動を進めました。

ところが、戻したサーバーに通信が集まると、また応答しなくなりました。Microsoft は、何がきっかけでそうなるのかを診断データで分析していると説明しています。

ここからは当社の見方です。止まっていた間に、利用者のパソコンやスマホのメールソフトは何度もつなぎ直そうとしています。一般に、こうした障害では、サーバーが戻った瞬間にそのつなぎ直しが一気に押し寄せ、戻ったばかりのサーバーがまた負荷で倒れることがあります。

Microsoft は、一部の地域で届く通信の種類を絞る、通信を少しずつ戻す、別の経路に振り分けるといった対応をとっています。昼の時点でも、通信の振り分けの偏りが続いていると説明していました。

## 政府にも影響：GSSに支障

尾崎官房副長官は、13日午前の会見で「政府の情報システムの基盤であるGSSにも支障がでている」と述べました。

GSS（ガバメント・ソリューション・サービス）は、行政機関が使うデジタルの基盤で、ネットワークの構築と運用をデジタル庁が担当しています。尾崎副長官は「マイクロソフト社の対応を注視していく」と述べています。

## 国会では、2週間前に「止まったとき」が問われていた

10月28日、参議院のデジタル社会の形成及び人工知能の活用等に関する特別委員会で、参政党の岩本麻奈議員が、システムの障害のときの回復力を取り上げていました。

岩本議員は、自治体のシステムがガバメントクラウドに移っていくことについて、こう述べています。

> 多くの自治体が同じ事業者や共通の基盤に依存することで障害が広域に波及する可能性もあります。

あわせて、2024年7月にセキュリティソフトの更新の不具合で世界中のWindows端末が止まった件を例に、復旧の手段についても指摘しています。

> 仮に復旧に必要なキーや情報が障害を起こしたシステムに依存していた場合、復旧手段そのものが失われかねないという問題です。

これに対して、内閣官房の大村真一内閣審議官は、政府機関のシステムの調達では「冗長化、バックアップ、復旧を含む情報システムの可用性に関する対策要件を策定し、調達仕様書等に明記することと定めているところでございます。」と答えています。

今回は、まさに「同じ事業者に頼っていると、1か所の障害が広く波及する」という形の障害になりました。

## 障害のあいだに、会社ができること

Microsoft 側の障害なので、利用者の会社の側でサーバーを直すことはできません。それでも、仕事への影響を小さくするためにできることはあります。

- **障害の情報は、Microsoft の公式の発表で確かめる**：管理センターに入れない場合でも、Microsoft の障害情報のページと、公式の障害情報のアカウントで経過が出ています。番号は EX1550543 と MO1550821 です
- **社内への連絡を、別の手段で出す**：メールも Teams も使えないと、「いま障害が起きている」「いつ戻るか分からない」を社員に伝える手段まで失われます。電話、ショートメッセージ、社内の掲示板など、Microsoft 365 以外の手段を決めておきます
- **取引先への急ぎの連絡は、電話か別のメールで**：送ったつもりのメールが届いていないことがあります。急ぎの見積もりや納期の連絡は、相手に届いたかを電話で確かめます
- **復旧したあとに、送れていないメールを確かめる**：送信トレイに残っているメール、相手から届いていないメールを確かめます
- **パスワードの再設定などを急いでしない**：サインインできないのは障害のせいなので、アカウントの設定を変えると、復旧後にかえって混乱します

## 止まっても仕事が続く形にしておく

今回のように、メールもチャットも会議もAIも1つのクラウドに頼っていると、1か所の障害で仕事がまとめて止まります。そして、利用者の側からは直すことも、復旧の時期を早めることもできません。

すべてを自社で持つ必要はありません。ただ、**止まると困る業務だけでも、自社のサーバーで動かして自社で復旧できるようにしておく**と、こうした障害のときの選択肢が増えます。たとえば、社内の連絡、掲示、承認の流れが社内で動いていれば、外のサービスが止まっても「いま何が起きているか」を社員に伝えられます。

当社では、社内の連絡・掲示板・会議室の予約・稟議の申請と承認を、オンプレミスで動かすグループウェアとして開発しています。

## よくある質問

### 2026年11月13日のマイクロソフトの障害は、何が使えなくなったのですか？

メールの Exchange Online のメールボックスにつながらなくなり、Outlook の Web 版、デスクトップアプリ、モバイルアプリが使えなくなりました。AIの Copilot にも影響が出ています。報道では、Teams など複数のサービスにも影響が出ています。

### 障害の原因は何ですか？サイバー攻撃ですか？

Microsoft は、サイバー攻撃ではないと説明しています。多くのサーバーが自動のヘルスチェックに失敗して予期せず使えなくなり、残りのサーバーに負荷が集中したことが原因です。アクセスが増えたためではないとしています。

### Teams の障害も同じ原因ですか？

報道では、今回の Microsoft 365 の障害で Teams など複数のサービスにも影響が出たとされています。Microsoft の発表では、影響を受けるサービスと機能の一覧は、管理センターの MO1550821 で案内されています。

### いつ復旧しますか？

11月13日15時30分の時点で、Microsoft は全面的な復旧の時期を示していません。15時12分の発表では、フロントエンドのサーバーの復旧と、通信の最適化を続けているとしています。

### マイクロソフトの障害の状況は、どこで確かめればよいですか？

会社の管理者の方は、Microsoft 365 管理センターの EX1550543 と MO1550821 で確かめられます。管理センターに入れない場合のために、Microsoft は公式の障害情報のページと、障害情報のXのアカウントでも経過を出しています。

### 政府や自治体にも影響は出ていますか？

尾崎官房副長官は、政府の情報システムの基盤であるGSS（ガバメント・ソリューション・サービス）にも支障が出ていると会見で述べました。
