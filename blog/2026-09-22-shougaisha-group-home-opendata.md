障害のある人の住まいを住所から探せる道具を作りました。作る途中で、数え方をひとつ変えなければいけないことに気づきました。

- できたもの: <https://kurage.exbridge.jp/kghome.php/?ref=vwork-kghome>
- 運営法人から探す: <https://kurage.exbridge.jp/kghome.php/corps?ref=vwork-kghome>
- オンプレミス版: <https://kappstore.exbridge.jp/app.php?id=bf709cfc7b0bf51a&ref=vwork-kghome>

## データは国が出しています

WAM NET（独立行政法人福祉医療機構）が、障害福祉サービス等情報公表システムのオープンデータをサービス種別ごとのCSVで配っています。**営利・非営利を問わず二次利用できる**と明記された公開データで、毎年3月末・9月末に更新されます。

住まいに関わる5種別だけで、2026年3月末時点の収録はこうです。

| サービス | 事業所 |
|---|---|
| 共同生活援助（グループホーム） | 16,022 |
| 短期入所 | 9,145 |
| 施設入所支援 | 2,565 |
| 自立生活援助 | 519 |
| 宿泊型自立訓練 | 220 |

合計28,471事業所。**緯度経度が全件入っている**ので、住所からの距離計算に外部のジオコーダは要りません。

## 最初に気づいたのは、定員が1件も無いことでした

共同生活援助の16,022件を読み込んで、定員の列を数えたら**0件**でした。空欄が多いのではなく、全件が空です。

これは「定員0人のグループホームが16,022か所ある」のではありません。**公表項目にそもそも入っていない**のです。短期入所（7,130件）や施設入所支援（2,435件）には定員が入っているので、データの欠損ではなく制度の側の話です。

だから画面から定員のカードも定員の列も外しました。「—」と表示して済ませることもできますが、それだと「定員が無い事業所」に見えてしまいます。「公表されていません」と書くようにしています。

## 「施設から地域へ」は、数字に出ていました

10時点ぶん（2021年11月末から半年ごと）のCSVを並べると、こうなります。

| 時点 | グループホーム | 施設入所支援 |
|---|---|---|
| 2021年11月末 | 10,012 | 2,484 |
| 2023年3月末 | 11,332 | 2,508 |
| 2024年3月末 | 12,987 | 2,535 |
| 2026年3月末 | **16,022**（1.60倍） | **2,565**（1.03倍） |

グループホームだけが増えて、入所施設はほとんど動いていません。「施設ではなく地域で暮らす」という方針は、少なくとも住まいの数のうえでは、この向きで進んでいます。

ただし**公表件数が増えた＝事業所が増えた、ではありません**。自治体の登録が進んだぶんが混ざります。だから画面では全国の増減を「公表された件数」と書いて、事業所数とは呼び分けています。

## 増えた側だけを見ても、分かりませんでした

同じ10時点を、逆から数えます。前の時点には載っていた事業所番号が、次の時点には載っていない。その数です。

**1,618か所のグループホームが、この4年半で公表データから消えていました。**

問題は、消え方が均等ではなかったことです。

| 最後に公表された時点 | 消えたグループホーム |
|---|---|
| 2023年9月末 | 111 |
| 2024年3月末 | 175 |
| 2024年9月末 | **473** |
| 2025年3月末 | 296 |
| 2025年9月末 | 206 |

2024年9月末のところだけ、明らかに跳ねています。何が起きたのか中を見ました。

**473か所のうち、202か所が1つの法人、52か所がもう1つの法人でした。** 残りは3か所以下が散らばっているだけです。

## だから、法人を主語にした画面を作りました

市区町村ごとに数えているうちは、この偏りは見えません。「大阪府で121か所減った」としか出ないからです。数える単位を法人に変えて、はじめて形が見えました。

作ったのは、法人ごとに次の4つを並べるページです。

1. いま公表されているグループホームの数
2. 住まい全体の数と、種別の内訳
3. 何都道府県に広がっているか
4. 公表データから消えた数

やってみて分かったのは、**消えた数だけを見てはいけない**ということでした。上位2社はこうなります。

| | 消えたグループホーム | いま公表されているグループホーム |
|---|---|---|
| A社 | 212 | **339** |
| B社 | 88 | **19** |

同じ「まとめて消えた」でも、中身がまったく違います。A社はいまのほうが多い。法人の再編で事業所番号が付け替われば、古い番号は「消えた」に数えられます。**住む場所が無くなったという話ではありません。** B社は逆で、実際に大きく減っています。

**どちらなのかは、公表データには書かれていません。** 消えた理由の欄が無いからです。だから画面は断定せず、2つの数を必ず並べて、読み分け方を文章で添えることにしました。

## 法人番号では束ねられませんでした

ここで詰まりました。法人ごとに数えるのだから法人番号を鍵にすればいい、と思って書いたら、同じ会社が何行にも割れたのです。

調べたら、公表データの法人番号は入力がばらばらでした。

- ある1社に、13桁の法人番号が**6種類**ついている
- 13桁ですらない値が604件（12桁、10桁など）
- 空が1,513件

番号で束ねると、同じ法人がばらけて「何か所消えたか」を数え落とします。最大手が212か所ではなく、176か所と30か所と6か所……に分かれてしまう。

そこで**正規化した法人名**（NFKC変換して空白を除去）を鍵にしました。

代わりに、同じ名前の別法人が混ざります。同名の社会福祉法人が複数の県に実在するケースで、384名義・3,186事業所がこれに当たります。完全な解決ではありません。だから法人ページには、見つかった法人番号を**全部**並べて出しています。「この法人には公表データ上で複数の法人番号が記録されています（入力ゆれです）」と添えて。

分からないものを、分かったように束ねない。妥協した理由も画面に書く。そこまでやって、やっと出せる数字だと思っています。

## ほとんどの法人は1か所しか持っていません

もうひとつ、数えて意外だったことを書いておきます。

全国16,022か所のグループホームを、**10,744法人**が運営しています。1法人あたり平均1.49か所です。

内訳を見ると、**1か所しか持っていない法人が8,557**。全体の79.6%です。2か所が1,354、3か所が379と続きます。

つまりこの分野は、小さな法人がほとんどを支えている一方で、上位には全国40都道府県に339か所を持つ法人がいる、という形をしています。「グループホームが増えた」と一言で言うとき、増えたのがどちらなのかで意味がまったく違います。

## できたもの

住所を入れると、近くのグループホーム・短期入所・施設入所支援が距離順に出ます。運営法人の名前がその場に出て、押せばその法人の全国の事業所に飛べます。

- 都道府県ページ47、市区町村ページ1,400超（政令市と東京23区は区ごと）
- 事業所ページ28,471、法人ページ5,288（2か所以上持つ法人）
- CSVとJSON API、sitemap.xml、llms.txt

PHP 1ファイルとSQLiteだけで動きます。データベースサーバーも常駐プロセスもポートも要りません。判定は置いた場所で完結して、外部のAIやAPIには何も送りません。

**空き状況は出しません。** 公表データに無いからです。家賃も食費も夜間の体制も同じく分かりません。入れるかどうかは事業所に聞くしかありません。そこは道具では埋められない部分です。
