# DESIGN

このファイルは、**見た目の品質が成果物の価値に直結する案件**で使います。

HP、LP、UI、ダッシュボード、営業資料、OGP画像など「デザインの良し悪しが伝わり方を決めるもの」を作る前に、
ここを埋めてからAIに実装させます。埋めずに作らせると、AIは無難で汎用的なものを出しがちです。

該当しない案件（社内スクリプト、データ処理など）では、このファイルは不要です。
