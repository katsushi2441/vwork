# WORKFLOW

このファイルは、**この案件で繰り返す作業の手順**を書く場所です。

同じ作業を2回以上頼むようになったら、ここに手順として残します。
そうすると次回から「WORKFLOW.mdの◯◯の手順で」と頼むだけで、AIが同じ品質で再現できます。

最初は空で構いません。作業しながら育てます。

---

## 手順のテンプレート

```markdown
## ◯◯を更新する

前提:
- 触るファイル:
- 必要な環境変数 / 設定:

手順:
1.
2.
3.

確認:
- （VERIFICATION.mdのどの方法で確認するか）

よくある失敗:
-
```

---

## 例: Webページを更新して公開する

前提:
- 触るファイル: `src/` 配下のHTML/PHP
- 公開先: `SERVERS.md` に記載（認証情報は `.env`）

手順:
1. 変更前のファイルをバックアップする。
2. 修正する。
3. 構文チェックする（`php -l` / `node --check`）。
4. 公開する。
5. `VERIFICATION.md` の手順で、公開URLのHTTPコードとスクリーンショットを確認する。

確認:
- 公開URLが200を返す
- スクリーンショットで表示崩れがない（PC幅・スマホ幅）

よくある失敗:
- アップロードしただけで完了にする（公開URLを見ていない）
- 一括置換の件数を確認せず、実は0件だったことに気づかない
